実験結果の読み方
================

``masterresearch`` 実行後に出力されるファイル群の見方をまとめる。指標そのものの定義はリポジトリ直下の ``README.md`` の「評価指標」を参照。

出力ファイル一覧
----------------

``--output-dir`` で指定した出力先ディレクトリ（デフォルト ``backLog``）配下に、以下の構成で出力される。

.. code-block:: text

   {output_dir}/{手法番号}_{手法名}/{関数番号}_{関数名}/{開始時刻}/
   ├── front_{手法番号}{関数番号}_{試行番号}.csv  # 試行ごとのパレートフロント
   └── trajectory_best.csv                        # 最良試行の世代ごとの軌跡

これとは別に、``--log-file`` で指定した実行記録CSV（デフォルト ``execution_log.csv``）に、実行1回分の統計が1行追記される。

front_*.csvの読み方
--------------------

各行が1つの非劣解（アーカイブに残った解）。列は ``f1``, ``f2``（``DTLZ1`` のみ ``f1``, ``f2``, ``f3``）で、それぞれの目的関数値。行数がそのまま「解の個数（GB数）」になる。

例（``MOPSO`` × ``Rastrigin`` の1試行分、抜粋）:

.. code-block:: text

   ,f1,f2
   0,0.0000774,141.669
   1,0.0006272,136.100
   2,0.0008864,110.166
   3,0.0031990,95.793
   4,0.0053554,67.056

execution_log.csvの読み方
--------------------------

1行が1回の実行（``TRIAL`` 回試行分の統計）に対応する。

.. list-table::
   :header-rows: 1

   * - 列名
     - 意味
   * - ``func_name`` / ``meth_name`` / ``topo_name``
     - 実行条件（関数名・手法名・トポロジー名）
   * - ``trial``
     - 試行回数
   * - ``processing_time``
     - 1試行あたりの平均処理時間 [s]
   * - ``ind0_avg`` / ``ind0_max`` / ``ind0_min`` / ``ind0_median``
     - 解の個数（GB数）の平均・最大・最小・中央値
   * - ``ind0_argmax`` / ``ind0_argmin``
     - 解の個数が最大・最小だった試行番号（``No.1`` 始まり）
   * - ``ind1_avg`` / ``ind1_max`` / ``ind1_min`` / ``ind1_median``
     - 被覆率の平均・最大・最小・中央値
   * - ``ind1_argmax`` / ``ind1_argmin``
     - 被覆率が最大・最小だった試行番号

``ind0`` が解の個数、``ind1`` が被覆率に対応する（記録される順序に由来）。

例（同上の実行、抜粋）:

.. code-block:: text

   year,month,day,func_name,meth_name,topo_name,trial,ind0_avg,ind0_max,ind0_min,ind1_avg,ind1_max,ind1_min
   2026,8,23,Rastrigin,MOPSO,None,2,12.0,16.0,8.0,0.484,0.500,0.469

trajectory_best.csvと粒子軌跡アニメーション
--------------------------------------------

全試行終了後、追加でもう1回実行した結果を、世代・解ごとに1行のロング形式で記録したもの。列は ``generation``, ``point_idx``, ``f1``, ``f2``（``DTLZ1`` のみ ``f3`` も）。

例（抜粋、いずれも世代0）:

.. code-block:: text

   generation,point_idx,f1,f2
   0,0,0.000826,188.911
   0,1,0.002574,139.210
   0,2,0.003196,103.403
   0,3,0.004068,102.030
   0,4,0.039768,98.238

``tools/graph_drawer.py`` に渡すと、世代ごとの解の分布をアニメーションで確認できる。

.. code-block:: bash

   $ python tools/graph_drawer.py <trajectory_best.csvのパス> [フレーム間隔ms]

tools/metrics_evaluator.py による事後評価
----------------------------------------------

``tools/metrics_evaluator.py`` は、実行済みの ``front_*.csv`` を後から読み込んで指標を計算するツール。3つのオプションがある。

``--rni``: 2手法を比較する
~~~~~~~~~~~~~~~~~~~~~~~~~~

2つの手法のパレートフロントを比較したい場合に使う。

.. code-block:: bash

   $ python tools/metrics_evaluator.py --rni

1つ目・2つ目の ``front_*.csv`` のパスを入力すると、2つを統合したフロント中で各手法が占める解の比率が表示される。値が大きい方が優勢。

``--val``: 1手法の解の個数・被覆率を再評価する
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1つの手法について、ディレクトリ内の全 ``front_*.csv`` から解の個数・被覆率の統計（平均・中央値・最大値・最小値）をまとめて再計算したい場合に使う。``execution_log.csv`` を紛失した場合や、後から改めて集計し直したい場合に有効。

.. code-block:: bash

   $ python tools/metrics_evaluator.py --val

``front_*.csv`` が格納されているディレクトリ（``出力ファイル一覧`` の ``{開始時刻}/`` ディレクトリ）を入力すると統計が表示される。

``--rniall``: 1手法を複数手法と比較する
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1つの手法（基準）を、他の複数手法（最大9つ）と1対1でRNI比較したい場合に使う。手法をまとめて総当たりで比較したい場合に、``--rni`` を何度も実行する手間を省ける。

.. code-block:: bash

   $ python tools/metrics_evaluator.py --rniall

基準となる ``front_*.csv`` のパスを入力した後、比較したい ``front_*.csv`` のパスを9つ分入力すると、それぞれとのRNI比較結果が順に表示される。

.. note::
   比較対象の数（現状9固定）は実装上ハードコードされている既知の制約。
