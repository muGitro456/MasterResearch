DFPO-MOPSO（SENIOR）
=====================

DFPO-MOPSOとは、:doc:`fpo_mopso` の問題点を踏まえて、FPO側の挙動に二つの変更を加えたメタヒューリスティクスのことである。本リポジトリのコード上では ``SENIOR`` という名前で実装されている。

条件式の緩和
------------

一つ目の変更は、FPが移動可能かどうかを判定する条件式の変更である。従来の条件式では、[0, 1)の乱数で重み付けした小数と[0, 1)の乱数を比較していたが、条件が厳しく移動できる粒子の数が少なかった。また、右辺の乱数が左辺の乱数よりも大きな値だった場合、どれほど適応度が高い粒子でも移動することができなかった。局所解から脱出できる性能があっても移動できなければ意味をなさないため、条件式から左辺の乱数項を削ることでFPと判定される粒子数を増加させ、問題の改善を図った。

移動指針へのPBestの追加
------------------------

二つ目の変更は、新たな移動指針の追加である。具体的には、粒子が移動する際、他の粒子の位置だけでなく、自身のPBestの位置も考慮して移動するように変更した。従来の移動方法では、他の粒子の位置に近づくように移動することで早期収束を回避していたが、移動方向が完全な無作為で決定されるため回避が不安定だった。PBestの位置にも近づくようにすることで移動方向が完全な無作為ではなくなり、早期収束回避の安定性が増した。
