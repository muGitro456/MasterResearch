MOPSO
=====

MOPSOとは、:doc:`pso` を多目的最適化問題用に拡張したメタヒューリスティクスのことである。

この手法では多目的に適用させるために、GBestを「群れ全体から見て、少なくとも一つの目的関数においては最良な点の位置」として再定義している。ゆえに、MOPSOにおいては、探索過程で多くのGBestを発見し更新していくことが、与えられた問題に対するパレート最適解集合の精度を上げることにつながる。

アーカイブによるエリート戦略
----------------------------

MOPSOではパレート最適解を効果的に発見するために、アーカイブを用いたエリート戦略を採用している。この戦略は、探索中に得られたGBestと既に保存されているGBestを比較し、少なくとも一つの目的関数値においては他より優れているGBestのみを保存するというものである。これにより、一度の探索で複数のGBestを同時に更新できる。

多様性の確保と混雑距離
----------------------

また、MOPSOでは解の多様性（Diversity）を確保するため、各粒子がアーカイブに保存されているGBestの中でも周辺が空いているGBestに近づくようにしている（本リポジトリでは、このようなGBestを「リーダー」と呼称する）。

あるGBest周辺の空き具合については、混雑距離（Crowding Distance）という指標を用いて評価する。混雑距離とは、ある解周辺の密度を表す値のことで、隣接する解によって作られる長方形の正規化された長辺と短辺の和として求められる。つまり、あるGBestの混雑距離が大きいということはそのGBestの周囲が空いていることを意味しており、その周辺をさらに探索できれば新しいGBestが見つかる可能性が高い。そのため、MOPSOでは粒子が移動する際、算出された各GBestの混雑距離に対してルーレット選択を適用してリーダーを決定し、粒子をその周辺に近づかせることで新たなGBestの発見を促す。
