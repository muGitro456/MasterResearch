PSO
===

PSO (Particle Swarm Optimization) とは、鳥や魚の群れ（Swarm）において、ある一匹が餌を発見すると群れ全体がその個体に倣って行動するという特性をモデル化した単一目的メタヒューリスティクスのことで、1995年にJ. KennedyとR. C. Eberhartによって考案された。

この手法では、最適化問題における最適解の候補を、「位置」と「速度」の情報を持つ粒子（Particle）として表現し、各粒子が与えられた問題における探索空間上での移動と現在位置の評価を繰り返すことで探索が進行する。

ここで、粒子は自身が探索した点の中で最も評価が良かった点の位置（Personal Best; PBest）を記憶し、群れ全体から見て最も評価が良かった点の位置（Global Best; GBest）を群れ全体に共有するという特性を持っている。そして、粒子はこの二つの最良点に近づくように移動するため、最初は探索空間上に散らばっていた粒子の群れが、探索が進むにつれて最適解（GBest）という一点に収束していく。これこそがPSOの特徴であり、解の収束速度が大きいという利点の要因でもある。
