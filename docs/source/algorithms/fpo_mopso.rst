FPO-MOPSO
=========

FPO-MOPSOとは、:doc:`fpo` と :doc:`mopso` を組み合わせたメタヒューリスティクスのことである。

この手法では、まずMOPSOのアルゴリズムを適用させた粒子群とFPOのアルゴリズムを適用させた粒子群の二つを作成する。次に、その二つの群に属する粒子たちをリーダーの位置を参考に移動させ、それぞれのアーカイブを更新する。そして、二つのアーカイブに保存されたGBestを統合し、その中におけるGBestを全体アーカイブに保存する。以上の処理を繰り返していくことで解探索が進行する。
