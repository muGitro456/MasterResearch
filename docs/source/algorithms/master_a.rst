MASTER_A
========

:doc:`dfpo_mopso` の問題点を踏まえ、そのMOPSO側のアルゴリズムに対して以下の三つの変更を加えた提案手法。

サブアーカイブ
--------------

一つ目の変更は、群を構成する粒子ごとにアーカイブを設定することである。従来のMOPSOでは、アーカイブは粒子群全体に対して一つのみ用意されていた。しかし、一つのアーカイブ上で更新を繰り返す従来の方式では解の多様性が失われやすい。そこで、本手法では各粒子に対して、それぞれに対応している個別のアーカイブを与え、各々でGBestを更新するように変更することで解の多様性の保持を図る。以降、各粒子に与えたアーカイブのことをサブアーカイブ（Sub-archive）と呼ぶ。

トポロジーに基づく近傍関係
--------------------------

二つ目は、全ての粒子に対してトポロジー（Topology）に基づいた近傍関係を適用させることである。一つ目の変更によって、各粒子ごとにサブアーカイブが存在し各々で更新が可能となった。しかし、それぞれの粒子が単独で探索を行うよりも他の粒子同士で連携しながら行う方が良いと見込まれる。そこで、本手法では全ての粒子をトポロジーの形状に従って接続し、それぞれの粒子に近傍関係（Neighborhood relationship）を与える。これにより、粒子同士に繋がりが生まれるため、近傍に属する粒子との連携が可能になった。

リーダー選択・アーカイブ更新の変更
-----------------------------------

三つ目は、リーダー選択とアーカイブ更新の仕様を変更することである。多目的最適化問題におけるGBestは多数存在しているため、ただ一点収束を目指す従来のような移動方式ではなく、探索空間上を網羅するように動いた上で収束に向かう形式の方がより多くのGBestを発見することができる。そこで、本手法では上記二つの変更点を利用した、新たなリーダー選択方法とアーカイブ更新方法を適用する。
