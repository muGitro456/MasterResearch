FPO
===

FPOとは、捕食者が獲物を探す際の振る舞いを模したメタヒューリスティクスのことで、2014年にS. YangとY. Satoによって提案された。

この手法では:doc:`pso` と同様に粒子を用いて探索を行う。しかし、PSOとは異なり、粒子はGBestの情報を用いずに移動する。これは、FPOにおける捕食者は群れることなく一匹で狩りをすることを想定しているからであり、移動の際には無作為に選択された他の粒子の位置に近づくように移動する。この特徴のおかげで、粒子が局所解に陥ったとしても脱出することができる。

適応捕食者（Fitness Predator）
-------------------------------

さらに、FPOには一定の条件式を満たした粒子を適応捕食者（Fitness Predator; FP）と判定し、FPと判定された粒子のみ移動できるという特徴がある。この条件式は、[0, 1)の一様乱数 r, r' と、目的関数値が小さいほど高くなる適応度（fitness）を用いて定義されている。この特徴は、条件式を満たすほどの高い適応度を持つ粒子であれば、移動後により良い解を見つける可能性が高いという考えのもとで設定されている。
