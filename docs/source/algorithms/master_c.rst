MASTER_C
========

:doc:`master_a` ではサブアーカイブを粒子ごとに用意する。しかし、粒子の数が多いほどサブアーカイブの数はもとより参照回数も増加するため、アルゴリズムの実行時間が掛かるようになると想定される。したがって、各粒子に対してサブアーカイブを用意するのではなく、粒子群を複数のグループに分け、そのグループごとに一つのサブアーカイブを用意する方式を適用した提案手法として、``MASTER_C`` を検討する。

以降、粒子群から分けられたグループのことをサブ粒子群、サブ粒子群によって構成される群のことをマルチ粒子群と呼称する。

:doc:`master_a` で述べたトポロジーに基づく近傍関係に関しては、一つのサブ粒子群を一つの頂点と見なすことで同様に構築することができる。本手法では、マルチ粒子群を用いたリングトポロジーが適用された手法を利用する。また、アーカイブ更新に関しても同様に処理可能であり、リーダー選択についてはサブ粒子群内の粒子には同じ近傍リーダーの位置を参照させることで対処する。
